# Laura’s Atelier — web académica

Sitio web estático con tres páginas: Inicio (`index.html`), Colección/Servicios (`servicios.html`) y Contacto (`contacto.html`).

## Publicación en GitHub + Vercel
1. Crear repositorio público `lauras-atelier` en GitHub.
2. Subir los cinco archivos de esta carpeta **a la raíz del repositorio** (no subir el ZIP sin extraer).
3. En Vercel: Add New → Project → Import Git Repository → elegir `lauras-atelier`.
4. Framework Preset: Other; Root Directory: `./`; Build Command: vacío; Output Directory: vacío (sitio estático).
5. Deploy. Abrir el dominio `.vercel.app` y probar las tres páginas y el menú móvil.

## Antes de entregar
- Sustituir `contacto@example.com` en `contacto.html` por un correo válido que quieras publicar; alternativamente quitar el enlace si no deseas mostrar un correo.
- Las fotografías son referencias externas de Unsplash; requieren conexión y pueden cambiar. Verificar que cargan. Las fotografías ilustran la estética, **no** productos reales de una marca.
- El proyecto es ficticio y no comercial; no recoge datos ni procesa compras.
- Capturar Inicio, HTTPS en navegador y panel de Vercel, y adjuntarlos al PDF del ejercicio.
